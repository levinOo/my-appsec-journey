# Лаборатория DevSecOps: Комплексное сканирование безопасности (Multistack Security Scanning)

Добро пожаловать в **Лабораторию DevSecOps**! Этот репозиторий представляет собой практическую среду для изучения и внедрения современных подходов к безопасности приложений (AppSec).

Основная цель этого проекта — продемонстрировать процессы внедрения и выявления уязвимостей на разных стеках технологий (Go и Python), а также построить автоматизированный CI/CD пайплайн для их обнаружения с использованием индустриальных стандартов и инструментов.

## 🎯 Обзор проекта

Проект включает в себя два целевых приложения, каждое из которых демонстрирует разные аспекты безопасности:

1. **Go App ("System Utils & User API")** — намеренно уязвимый REST API на языке Go. Приложение выступает в роли тренировочного стенда ("мишени") для практики работы со сканерами безопасности. В нем заложены классические уязвимости:
   - Command Injection & Path Traversal
   - SQL Injection
   - Захардкоженные секреты
2. **Python App ("Nexus News")** — форк реального веб-приложения на Python. В отличие от Go-приложения, исходный код здесь написан относительно безопасно, но проект использует устаревшие зависимости, содержащие критические уязвимости (CVE).

На базе этих проектов мы практикуем настройку сканеров на всех этапах жизненного цикла DevSecOps:
* **SAST (Static Application Security Testing):** Анализ исходного кода на наличие логических ошибок (Gosec, Semgrep, Bandit).
* **SCA (Software Composition Analysis):** Поиск известных уязвимостей в сторонних зависимостях (Trivy).
* **Secret Scanning:** Обнаружение захардкоженных секретов и учетных данных (Gitleaks).
* **DAST (Dynamic Application Security Testing):** Активное зондирование запущенного приложения на наличие эксплуатируемых слабостей (OWASP ZAP).

## 📂 Структура репозитория

Репозиторий организован следующим образом:

```text
my_appsec/
├── .github/
│   └── workflows/
│       └── security.yml       # CI/CD пайплайн GitHub Actions (SAST, SCA, DAST)
├── go-app/                    # Намеренно уязвимое приложение на Go
│   ├── cmd/server/main.go     # Точка входа и регистрация роутов
│   ├── config/config.go       # Конфигурация с захардкоженными секретами
│   ├── internal/
│   │   ├── db/sqlite.go       # Настройка in-memory базы данных
│   │   └── handlers/          # Уязвимые обработчики (SQLi, Command Injection, Path Traversal)
│   ├── gosec-report.md        # Отчет об аудите SAST (находки Gosec)
│   ├── semgrep-report.md      # Отчет об аудите SAST (находки Semgrep)
│   └── swagger.json           # Спецификация OpenAPI (опционально)
├── python-app/                # Приложение на Python с уязвимыми зависимостями
│   └── report.md              # Комплексный отчет об аудите (Bandit, Trivy, Gitleaks)
└── README.md                  # Вы находитесь здесь
```

## 🚀 CI/CD Пайплайн (GitHub Actions)

В проекте настроен автоматизированный процесс сканирования безопасности при каждом push и pull request в ветку `main` (`.github/workflows/security.yml`). 
В пайплайн интегрированы:
- **Gosec** (SAST для Go)
- **Semgrep** (SAST для Go/Python)
- **Trivy** (SCA для поиска уязвимых пакетов)
- **OWASP ZAP** (DAST Baseline Scan по запущенному локально приложению)
