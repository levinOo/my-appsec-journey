# Лаборатория DevSecOps: Комплексное сканирование безопасности (Multistack Security Scanning)

Добро пожаловать в **Лабораторию DevSecOps**! Этот репозиторий представляет собой практическую среду для изучения и внедрения современных подходов к безопасности приложений (AppSec).

Основная цель этого проекта — показать, как намеренно внедрять типичные уязвимости в веб-приложение, а затем построить надежный, автоматизированный CI/CD пайплайн для их обнаружения и блокировки с использованием индустриальных стандартов и инструментов.

## 🎯 Обзор проекта

В этом репозитории находится намеренно уязвимый REST API на языке Go ("System Utils & User API"). Мы используем это приложение как мишень для практики настройки и интерпретации результатов различных сканеров безопасности на всех этапах жизненного цикла DevSecOps:

* **SAST (Static Application Security Testing):** Анализ исходного кода на наличие логических ошибок.
* **SCA (Software Composition Analysis):** Поиск известных уязвимостей в сторонних зависимостях (библиотеках).
* **Secret Scanning:** Обнаружение захардкоженных секретов и учетных данных.
* **DAST (Dynamic Application Security Testing):** Активное зондирование запущенного приложения на наличие эксплуатируемых слабостей.

Репозиторий организован следующим образом:

```text
appsec-lab-multistack/
├── .github/
│   └── workflows/
│       └── security.yml    # CI/CD пайплайн GitHub Actions (SAST, SCA, DAST)
├── go-app/                 # Намеренно уязвимое приложение на Go
│   ├── cmd/
│   │   └── server/
│   │       └── main.go     # Точка входа и регистрация роутов (маршрутов)
│   ├── config/
│   │   └── config.go       # Конфигурация (содержит захардкоженные секреты)
│   ├── internal/
│   │   ├── db/
│   │   │   └── sqlite.go   # Настройка in-memory базы данных
│   │   └── handlers/
│   │       ├── system.go   # Уязвимости Command Injection и Path Traversal
│   │       └── user.go     # Уязвимости SQL Injection
│   ├── go.mod              # Описание зависимостей (содержит уязвимые пакеты)
│   └── swagger.json        # Спецификация OpenAPI для нацеливания сканера DAST
├── sast-report.md          # Отчет о ручном аудите SAST (находки Gosec)
├── semgrep-report.md       # Отчет о ручном аудите SAST (находки Semgrep)
└── README.md               # Вы находитесь здесь
