## 🔍 2. Статический анализ кода (SAST)

**Инструмент:** `Bandit`
**Цель:** Исходный код проекта Python

*Примечание аудитора: В ходе первоначального сканирования Bandit обработал более 380 000 строк кода, так как в зону покрытия попала директория виртуального окружения (`.venv`). При фильтрации ложных срабатываний (False Positives) из сторонних пакетов, в самом коде приложения обнаружена одна уязвимость.*

### 2.1. Использование слабого алгоритма хэширования (CWE-327)
* **Файл:** `smart_deduplicator.py:134`
* **Критичность:** HIGH (Высокая)
* **Описание:** `return hashlib.md5(key_phrases_str.encode('utf-8')).hexdigest()[:12]`. Использование MD5 считается небезопасным в криптографическом контексте, так как алгоритм подвержен атакам нахождения коллизий.
* **Рекомендация:** Если этот хэш используется не для криптографии (например, просто для генерации уникального ID статьи), рекомендуется явно указать это: `hashlib.md5(..., usedforsecurity=False)`. Если это связано с безопасностью — заменить на `hashlib.sha256()`.

## 📦 3. Анализ состава ПО / Зависимостей (SCA)

**Инструмент:** `Trivy`
**Цель:** Файл `requirements.txt`
**Статус:** 🔴 Найдено 26 уязвимостей (4 High, 11 Medium, 11 Low)

Разработчик не обновлял библиотеки (в частности `aiohttp` и `lxml`), что привело к накоплению известных уязвимостей (CVE). Ниже представлены наиболее критичные из них:

### 3.1. Уязвимости фреймворка aiohttp (Множественные CVE)
* **Установленная версия:** `3.9.1`
* **Критичность:** HIGH / MEDIUM
* **Описание:** В текущей версии присутствует целый букет уязвимостей:
  * **CVE-2024-23334 (High):** Directory Traversal (Обход каталога). Позволяет злоумышленнику читать произвольные файлы на сервере.
  * **CVE-2024-30251 (High):** Denial of Service (DoS) при обработке некорректных POST-запросов.
  * Множественные уязвимости Request Smuggling (Контрабанда запросов) и XSS.
* **Рекомендация:** Обновить `aiohttp` как минимум до версии `3.13.4` (или актуальной `3.x.x`).

### 3.2. XXE Injection в lxml (CVE-2026-41066)
* **Установленная версия:** `5.3.0`
* **Критичность:** HIGH
* **Описание:** Настройки парсера по умолчанию (`iterparse` и `ETCompatXMLParser`) позволяют выполнять атаки XXE (XML External Entity), что может привести к чтению локальных файлов сервера при обработке вредоносных XML-документов.
* **Рекомендация:** Обновить библиотеку `lxml` до версии `6.1.0` и выше.

### 3.3. Уязвимость python-dotenv (CVE-2026-28684)
* **Установленная версия:** `1.0.1`
* **Критичность:** MEDIUM
* **Описание:** Уязвимость перезаписи произвольных файлов через следование по символическим ссылкам (Symlink following).
* **Рекомендация:** Обновить `python-dotenv` до версии `1.2.2`.
